# keywords.md — 보험 키워드 뱅크 + 검색자 페르소나

> 사용법: /write 때 소재에 맞는 **메인 1개(지역명 포함)** + 서브 2~3개(소제목 배치)를 고른다.
> 메인 키워드는 띄어쓰기까지 이 표기 그대로 본문에 1회 이상. 검색량·경쟁도는 사용자가 확인한 값만 기록 (추정 금지).
> 사용한 메인 키워드는 post-history.md 에 기록 → 같은 메인 키워드 연속 사용 금지 (자기잠식).

## 지역 접두어
- 대면: `목포` · `영암` · `해남` · `강진` (+ 생활권 표기: `목포 하당`, `영암 삼호` 등은 사용자 확인 후 추가)
- 비대면: `전국`, `전화 보험상담`, `비대면 보험상담`

## 클러스터별 키워드 (메인 후보 = 지역 + 키워드)

### 1. 상담·설계사 (문의 직결 — CTA 강하게)
보험설계사 · 보험상담 · 보험 무료상담 · 보험 점검 · 보험 리모델링 · 보험 비교 · 보험 분석 · 보험 다이어트 · 보험료 줄이기 · 보험 정리

- 페르소나: 목포 거주 42세 맞벌이 엄마. 보험료가 월 50만 원 넘게 나가는데 뭐가 뭔지 모름. 지인 설계사한테 묻기는 부담스럽고, "이거 다 필요한가" 불안.

### 2. 실손(실비)보험

- 페르소나: 영암 50대 자영업자. 갱신 안내문 보고 보험료 오른 걸 알고 "4세대로 바꿔야 하나" 고민. 손해 볼까 봐 결정 못 함.

## 서브 키워드 고르는 법
- 메인과 같은 클러스터에서 2~3개, **소제목에 그대로** 배치.
- 예) 메인 `목포 실비 청구` → 서브: `실비 청구 서류` / `실비 자기부담금` / `보험금 청구 기간`

## 태그 세트 기본형 (5~10개)
- 메인 키워드 1 + 서브 2~3 + 지역 2 (예: 목포, 전남) + 주제 2 (예: 보험상담, 보험정보) + 브랜드 1(업체명 확정 후)
