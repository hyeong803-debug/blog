# playbook.md — 쿠팡파트너스 구매가이드·비교글 공식 (shop 블로그)

> 목표: "써 본 척"이 아니라 **"대신 다 따져 준 사람"**으로 신뢰를 얻어 클릭과 구매를 만든다.
> 거짓 경험담은 위법(기만 광고)이고, 들키면 블로그가 끝난다. 정직하게 리서치를 많이 하는 쪽이 오래 벌고 더 많이 번다.

## 1. 검색 의도별 글 유형 — 메인 키워드 형태로 고른다
| 의도 | 키워드 형태 | 글 구조 | 전환력 |
|---|---|---|---|
| 탐색 | `OO 추천`, `OO 순위`, `가성비 OO` | 상황별 TOP3 → 제품별 섹션 | ★★★ |
| 비교 | `A vs B`, `OO 비교` | 기준별 대결 → 상황별 승자 | ★★★★ (구매 직전) |
| 학습 | `OO 고르는 법`, `OO 구매 가이드` | 기준 5개 → 기준 충족 제품 | ★★ (상단 퍼널, 키워드 넓음) |
| 검증 | `OO 단점`, `OO 후기` | 후기 통계 → 불만 패턴 → 대안 | ★★★★ |
| 시즌 | `어버이날 선물`, `장마 제습기` | 예산별·대상별 추천 | ★★★ (피크 3~4주 전 발행) |

## 2. 글 뼈대 (구매가이드 기본형) — 블록 순서
0. **쿠팡파트너스 표기** (일반 text, 지정 문구 그대로) — 생략 불가
1. **Yes-set 도입** — 페르소나 상황을 2~3문장 연속 적중 + 결론 예고
   - 예: "상세페이지 열 개쯤 열어 두셨죠. 다 좋다는데 뭐가 다른지는 모르겠고요. 결론부터 말씀드리면, 쓰는 공간 크기만 정하면 답이 둘로 줄어듭니다."
2. **권위 한 줄 (정직 리서치형)** — `authority-lines.md`
3. **결론 먼저** — `summary` 카드 + 같은 내용 텍스트 3줄 ("○○이면 A / △△이면 B / 고민되면 C")
4. 소제목 **고르는 기준** — `criteria` 카드 + "✓ 기준 - 이유" 텍스트 (기준은 구매자 불만에서 역산)
5. **비교표** — `compare` 카드 + 표를 읽어 주는 텍스트 2~4줄 (이미지는 검색에 안 잡힘)
6. 제품별 소제목 "제품명 — 이런 분께" × 3~5
   - 한 줄 정의 → 후기 장점 ("구매자 후기에서는 ~") → 후기 단점 → 확인할 스펙 → `proscons` 카드(선택) → `cta` 카드(선택) → **링크 카드**
7. 소제목 **이런 분은 사지 마세요** — 신뢰 장치. 단점 공개가 전환율을 올린다
8. **FAQ 2~3개** — 롱테일 키워드 흡수 ("○○ 소음 심한가요?")
9. **마무리** — 결론 재강조 + 메인 키워드 + 표기 문구 1회 더 + 최종 링크

## 3. 설득 장치 (전부 정직하게 쓸 수 있는 것만)
- **결정 대행:** "고민되면 B" — 선택 피로를 덜어 주는 문장이 클릭을 만든다.
- **상황 세분화:** 원룸/신혼집/아이 있는 집 → 독자가 "내 경우"를 찾게 한다.
- **단점 먼저:** 제품마다 단점 1개 이상. 단점이 있어야 장점이 믿긴다.
- **사회적 증거 (진짜 숫자만):** "후기 120개 중 소음 불만 31건" — 직접 센 숫자만. `reviewstats` 카드.
- **손실 회피:** "잘못 사면 반품 배송비에 재포장까지" — 사실인 범위에서.
- **앵커링:** 프리미엄 → 가성비 순서로 보여주면 가성비가 더 싸 보인다.
- **선택지 3~5개:** 그 이상은 결정을 미루게 만든다.
- **링크 문구 = 행동 + 얻는 것:** "가격·최신 후기 확인하기" ✓ / "구매하기" ✗ (압박감)
- **투명성:** "링크는 쿠팡 상품 페이지로 연결됩니다" — 마찰을 줄인다.

## 4. 후기 활용 규칙 (핵심)
- 후기는 **사용자가 쿠팡 상품 페이지에서 직접 복사해 붙여넣은 것만** 쓴다 (자동 수집·크롤링 금지 — 쿠팡 약관·저작권).
  - 저장 위치: `drafts/<초안>.reviews.md` (git 제외). 상품명별로 구분해 붙여넣기.
- Claude 는 후기를 **세어서** 주제별로 묶는다 (장점 Top3 / 불만 Top3, 건수 포함). 센 숫자를 `meta.reviewsAnalyzed` 와 카드에 그대로.
- 본문에선 **남의 말로**: "구매자 후기에서는 ~라는 말이 많았습니다" / "불만 후기 상당수가 ~". 1인칭 경험("써 보니", "제가 써 본") 금지.
- 문장 통째 복사 금지 → 요약·의역. 짧은 인용은 한 줄 이내 + "구매자 후기 중" 출처 표시.
- 본인이 실제로 산 제품만 `meta.usedPersonally` 에 넣고 그 제품에 한해 실사용 표현 + 본인 실사진.

## 5. 사실 정보 규칙
- 스펙·구성품·크기·무게 = 사용자가 붙여넣은 상품 정보(`drafts/<초안>.products.md`)에 있는 것만.
- 가격은 수시로 바뀐다 → 숫자를 쓰면 "○월 ○일 기준" + `meta.priceCheckedAt`. 기본은 "가격대"나 "링크에서 확인".
- "최저가", "1위", "품절 임박", "오늘만" 같은 표현은 근거 없으면 금지 (lint 가 잡음).
- 건강·미용 제품: 질병 치료·예방, 효능 단정 금지 (식품표시광고법·화장품법·의료기기법).

## 6. 이미지 전략
- **render_cards.js 카드** (summary / compare / criteria / proscons / reviewstats / score / cta) = 독창 이미지 → 유사이미지 회피 + 체류시간
- 쿠팡 상세페이지 이미지 무단 사용 금지 (판매자 저작권). 쓸 수 있는 것: 사용자 직접 촬영(매장·실물), 직접 만든 카드, AI 연출 이미지("AI로 만든 이미지" 표기, 실제 제품 사진처럼 쓰지 않음).
- 카드 핵심 내용은 반드시 텍스트로도 (lint_shop 이 검사).

## 7. 네이버 저품질 회피 (제휴 블로그 특화)
- 하루 1건 이하, 주 3~5건. 같은 상품 반복 글 금지.
- 제휴 링크는 상품당 최대 2회 (섹션 끝 + 마무리), 글 전체 상품 수 × 2 + 1 이내.
- 정보 비중을 높게: 고르는 기준·FAQ·단점이 링크보다 길어야 한다.
- 카테고리별 시리즈로 C-Rank 주제 일관성 확보 (예: "주방가전 비교" 시리즈 10편).
- 발행 후 24시간 수정 금지, 링크 교체도 마찬가지.

## 8. 시즌 캘린더 (피크 3~4주 전 발행)
1월 설 선물·난방용품 / 2월 신학기·졸업 선물 / 3월 이사·봄맞이 청소 / 4월 캠핑·미세먼지 / 5월 어버이날·가정의 달 / 6월 제습기·선풍기·장마 / 7월 에어컨·휴가 / 8월 휴가·개학 / 9월 추석 선물 / 10월 가습기·캠핑 / 11월 블랙프라이데이·김장 / 12월 크리스마스·연말 선물·난방
