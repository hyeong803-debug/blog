# shop/keywords.md — 전 품목 키워드 설계법

> 품목: 전체. 검색량·경쟁도는 사용자가 네이버 검색광고 키워드도구 등에서 확인한 값만 기록 (추정 금지).
> 사용한 메인 키워드는 post-history.md 에 기록 → 같은 키워드 반복 금지.

## 키워드 조합 공식
`[품목]` × `[의도어]` × `[수식어]`
- 의도어: 추천 · 비교 · 순위 · 고르는 법 · 단점 · 후기 · vs · 가성비 · 선물
- 수식어(롱테일 — 경쟁 낮고 전환 높음): 원룸 · 자취 · 신혼 · 아기 · 강아지 · 소음 적은 · 저렴한 · 10만원대 · 부모님 · 직장인 · 캠핑용
- 예: `원룸 제습기 추천`, `아기 있는 집 공기청정기`, `10만원대 무선청소기 비교`, `부모님 안마기 선물`

## 품목 묶음 (시리즈로 운영 → C-Rank 주제 일관성)
| 묶음 | 대표 품목 |
|---|---|
| 주방가전 | 에어프라이어, 전기포트, 커피머신, 식기세척기, 음식물처리기, 믹서기 |
| 생활가전 | 무선청소기, 로봇청소기, 제습기, 가습기, 공기청정기, 선풍기·서큘레이터, 전기요 |
| 생활용품 | 수건, 칫솔·전동칫솔, 세제, 수납함, 침구, 매트리스 토퍼 |
| 육아 | 기저귀, 물티슈, 젖병, 아기띠, 유모차, 카시트 |
| 반려동물 | 사료, 고양이 모래, 자동급식기, 펫 드라이룸 |
| 디지털 | 무선이어폰, 보조배터리, 충전기, 키보드, 모니터암, 태블릿 거치대 |
| 캠핑·차량 | 캠핑의자, 랜턴, 차량용 청소기, 블랙박스, 방향제 |
| 건강·뷰티 | 마사지건, 체중계, 헤어드라이어, 고데기 (⚠️ 효능 표현 주의) |
| 선물 | 어버이날, 집들이, 출산, 생일, 직장 상사 — 예산별 |

## 페르소나 예시 (글마다 새로 정의)
- `원룸 제습기 추천`: 서울 원룸 자취 2년차 27세 직장인. 장마철 빨래 냄새·곰팡이 스트레스. 10만 원 안쪽 원함, 소음에 예민.
- `부모님 안마기 선물`: 30대 중반 맞벌이. 어버이날 일주일 전, 실패하기 싫고 "비싸 보이는데 쓸모 있는" 선물을 원함.
