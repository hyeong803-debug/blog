# photo-guide.md — 업종별 필수 촬영 컷 가이드

> 목표: 글당 10~15장, 장당 텍스트 2~4줄. **사진 재사용 금지** (post-history.md 에 사용 파일명 기록).
> 실사 사진이 기본, AI 생성 이미지는 글당 1~3장 이내 (캐릭터·개념 설명용). AI 이미지를 실제 사진처럼 쓰지 않는다.

## A. 보험 정보성 글 (청구 방법·보장 분석·리모델링 등)
| # | 컷 | 비고 |
|---|---|---|
| 1 | 대표 컷: 상담 책상 위 노트·펜·계산기 (사람 X 또는 손만) | 썸네일 후보 |
| 2 | 손으로 쓴 설명 메모 / 화이트보드 그림 | **가장 강력한 독창 이미지** — 핵심 개념마다 1장 |
| 3 | 서류 예시 (진료비 영수증·세부내역서·증권 등) | ⚠️ 이름·주민번호·증권번호·주소·연락처·병원명·진단명·계좌 **전부 모자이크** |
| 4 | 휴대폰 화면 (보험사 앱 청구 메뉴 등) | 개인정보·잔액 모자이크 |
| 5 | 사무실·상담 공간 (전경, 간판 없이도 OK) | 지역 신뢰 |
| 6 | 이동 컷: 목포·영암·해남·강진 지역 풍경/도로 표지 | 지역 키워드 근거 |
| 7 | AI 캐릭터 이미지 (설명하는 포즈, 말풍선) | 캡션 "AI로 만든 이미지" |
| 8 | 체크리스트 카드 이미지 (직접 만든 그래픽) | 인용구 대신 쓸 수도 |

## B. 상담·일상 글 (브랜딩)
- 출장 상담 가는 길 / 지역 명소 / 오늘의 메모 / 책상 정리 / 공부 중인 자료 / 계절 사진
- 고객 등장 시: 얼굴·차량 번호판·집 주소 노출 금지 → 모자이크. 고객 사례는 **동의 + 식별 불가** 수준으로.

## C. 체험단·협찬 리뷰 글 (체험단 선발 목표)
- 외관(간판+입구) → 주차장 → 내부 전경 → 좌석 → 메뉴판(가격 보이게) → 메뉴별 클로즈업 → 단면/디테일 → 부가(화장실·키즈존 등) → 영수증(협찬이면 생략 가능) → 주변 풍경
- 타인 얼굴·번호판·직원 명찰 → 모자이크

## 모자이크 대상 (mosaic.js 필수)
- 타인 얼굴, 차량 번호판, 전화번호, 주소, 이름, 주민번호, 증권/계좌번호, 병원명·진단명(민감정보), 화자 본인 실물 얼굴(공개 명시 전엔 기본 모자이크)
