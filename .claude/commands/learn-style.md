# /learn-style

입력: $ARGUMENTS

1. **사용자가 붙여넣은 글만** 사용한다. URL 만 받았으면 WebFetch 를 한 번만 시도하고, 네이버 도메인 차단 등으로 실패하면 재시도하지 말고 "본문을 그대로 붙여넣어 주세요"라고 요청한다. 검색·크롤링으로 글을 모으지 않는다.
2. 글이 1편뿐이면 결과의 신뢰도가 낮다고 알리고 2~3편을 요청 (그래도 진행은 가능).
3. 측정: 평균 문장 길이, 한 줄당 문장 수, 종결어미 Top 5와 비율(단정형:친근형), 접속·전환 표현, 이모지 빈도·종류·위치, 도입부/마무리 패턴, 소제목 스타일, 자주 쓰는 표현, 안 쓰는 표현.
4. `data/blogger-profile.md` 와 비교해 **충돌 지점**을 보고한다 (예: 프로필은 단정 7:3인데 실제 글은 친근형 위주). blogger-profile 을 바꿀지는 사용자에게 묻는다 — 임의로 바꾸지 않는다.
5. `data/style-profile.md` 의 측정 항목을 채우고, 학습 날짜·편수를 기록. 원문 전체를 저장하지 말고 특징과 짧은 예문만 남긴다.
