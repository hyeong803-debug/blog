# /analyze-trends

입력: $ARGUMENTS

1. 분석 대상은 **사용자가 붙여넣은 글만**. 검색 결과 자동 수집·크롤링 금지. 네이버 본문 WebFetch 가 막히면 재시도하지 말고 붙여넣기를 요청한다.
2. 키워드와 노출 위치(스마트블록 / 인기글 / 블로그 탭 순위)를 사용자에게 확인 (모르면 "미상").
3. 글마다 측정: 제목 길이와 키워드 위치, 본문 글자 수, 사진 수, 소제목 수와 문구, 인용구 수, 메인 키워드 반복 횟수, 도입 패턴(후킹 유형), 권위 장치, CTA 위치, 지도·동영상 유무, 협찬 표기.
4. 공통 패턴 3~5개 + **우리가 이길 틈** (상위 글에 없는 실측 정보, 지역 디테일, 솔직함) 2~3개를 도출.
5. `data/trends.md` 에 `## <키워드> (날짜, N편)` 섹션으로 추가. 기존 섹션이 있으면 날짜와 함께 갱신 이력을 남긴다.
6. 결과가 CLAUDE.md 글쓰기 공식과 충돌하면 보고만 하고, 공식 변경은 사용자 승인 후.
